# Pixcall Plugin Samples

Small, self-contained examples for building plugins with
[Pixcall](https://pixcall.com/). Each sample focuses on one plugin capability,
from viewers and inspectors to independent-window editors.

Use these projects to learn how Pixcall plugins work, run a plugin locally, and
start adapting a sample into your own plugin.

## Start here

New to Pixcall plugin development? The
[Getting Started guide](docs/getting-started.md) walks you through installing
the tools, running your first sample, testing it in Pixcall, and building a
packaged plugin.

## Samples

- [`exif-inspector-sample`](./exif-inspector-sample/) — EXIF metadata inspector.
- [`image-editor-sample`](./image-editor-sample/) — image cropping editor.
- [`pdf-viewer-sample`](./pdf-viewer-sample/) — PDF viewer plugin.
- [`slideshow-sample`](./slideshow-sample/) — fullscreen slideshow command plugin.

Each sample is an independent project with its own dependencies and development
server. Choose one and open its README for feature-specific instructions.
